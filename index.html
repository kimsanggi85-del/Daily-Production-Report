출하 준비율 출하가능 SET ÷ 확정출하

※ 흰 배경 셀은 직접 수정 가능합니다 (공정재고 IN/OUT · 차수별 확정출하 · 소재 발주량). 값 입력 후 Enter 시 재고합계 · 출하가능 SET · 과부족 · 대시보드가 자동 재계산됩니다.
※ 차수 이름과 납기일은 위 주황색 칩에서 바로 수정, + 차수 추가 / ×로 증감할 수 있습니다. 월이 바뀌면 + 새 월 등록으로 새 출하월을 만들고 수량만 입력하세요. 공정재고는 모든 월이 공유합니다.
※ 출하는 SET 단위 → 출하가능 SET = MIN(INNER 재고, OUTER 재고). 과부족 = 출하가능 SET − 확정출하 합계.
※ 잔량 = 출하가능 SET(검사대기 포함) − 해당 차수까지 누적 확정출하.

※ 납품 Pallet = 품목별 수량 ÷ Pallet 단위(1106CB·1106CA 2,000 / 그 외 1,500). 단위는 아래 표에서 조정할 수 있습니다.
