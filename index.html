이 프로그램이 하는 일

고객사별로 5개 엑셀 파일(SKF씰, 세동산업, ATC, 부강스프링, 진양오일씰)에 나눠 쓰던 생산일보를 한 곳에 모았습니다. 하루 작업이 끝나면 설비별로 한 줄씩 입력하면 되고, 가동시간·가능수량·가동율·효율은 예전 엑셀과 같은 식으로 자동 계산됩니다.

  1. 가동시간 = 근무시간 − 정지시간 (분)
  2. 가능수량 = SPM × (근무시간 − 휴식·식사시간)
  3. ATC 양식은 근무시간에서 식사 60분을 빼고 가능수량을 계산합니다. 엑셀을 가져오면 이 값이 자동으로 잡히고, 직접 입력할 때는 고객사의 최근 값이 기본으로 채워집니다.
  4. 가동율 = 가동시간 ÷ 근무시간
  5. 효율 = 실적수량 ÷ 가능수량

매일 하는 일 (5분)

  1. 왼쪽 일보 입력 클릭 → 날짜는 오늘로 자동 설정
  2. MES 실적 불러오기를 누르면 그날 MES 일 생산수량(생산마감)과 불량폐기를 읽어 설비별로 줄을 만들어 줍니다. 근무시간·작업자·정지사유만 확인·수정하고 저장하면 됩니다 (2026년 9월분부터).
  3. 설비 선택 → 고객사 선택 → 품번 선택하면 품명·SPM이 자동으로 채워짐
  4. 작업자, 근무시간(분), 정지시간(분), 실적수량, 불량수량 입력
  5. 정지사유는 아래 버튼을 눌러 조합 (조회 · 금형점검 · 소재교환 …), 특기사항에 불량 내용 기록
  6. 저장 (또는 Ctrl+Enter). 같은 설비를 어제도 돌렸으면 전일 동일설비 불러오기로 한 번에 채운 뒤 수량만 고치면 됩니다.
  7. 화면 아래 표에서 방금 입력한 줄을 바로 수정·삭제할 수 있습니다.

매월 하는 일

  1. 월간 집계: 예전 "월MH당제품_DB" 시트와 같은 설비×품번 집계표. 엑셀 내려받기로 보고서에 붙입니다.
  2. 품목별 일별표: 예전 "현황" 시트처럼 품번별로 날짜 칸에 생산수량이 들어갑니다.
  3. 월간 보고서: 예전 "가동율_효율 양식" 시트. 주차별·당월·전월 비교는 자동이고 문제점·대책·인원·특이사항만 적으면 됩니다. 적은 내용은 서버에 함께 저장됩니다. 대표님 보고용은 PDF 내려받기(A4 가로)를 쓰시면 됩니다.
  4. 데이터 관리 → 백업 파일 내려받기: 월 1회.

새 품번·설비·작업자가 생기면

기준정보에서 추가합니다. 품번은 고객사와 함께 등록해야 입력화면에서 고객사를 고르면 해당 품번만 나옵니다. 기본 SPM을 넣어 두면 입력이 빨라집니다.

자료는 어디에 저장되나요

입력 즉시 이 기기(브라우저)에 저장되고, 곧바로 서버에도 올라갑니다. 다른 PC나 휴대폰에서 같은 파일을 열면 같은 자료가 보입니다. 왼쪽 아래 초록 점이면 정상, 빨간 점이면 서버 연결 실패(이 기기에는 저장됨)입니다.
